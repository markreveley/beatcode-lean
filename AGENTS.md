# For the next agent

Read HANDOFF.md first, then README.md and doctrine/. The doctrine is the
blocks in the form inside the code blocks of README.md and doctrine/;
everything else is commentary and binds nothing.

The operator's standing rule, recorded in HANDOFF.md under "Guardrails
for the next agent": discuss new work before acting. Read, report what
you find, and wait. File nothing, run nothing, change nothing until the
operator has discussed it with you. Reading and reporting are permitted.

Only the operator ratifies anything. Agents draft, check and record.
